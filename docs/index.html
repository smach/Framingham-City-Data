Framingham City Data (Unofficial)

This project collects data about Framingham, Massachusetts and puts it in a form that’s easy to analyze. It focuses on election results – City and Town races, state and federal races in Framingham, and turnout, all by precinct – and also has precinct and district maps, property records and Census data.

Every dataset is here in two forms: the original files (the clerk’s PDFs, downloaded shapefiles, and so on, in data-raw/) and analysis-friendly versions (in data/).

Quick start

All election results are in one file, one row per election, race, candidate and precinct. In R:

library(dplyr)
results <- readr::read_csv("https://raw.githubusercontent.com/smach/Framingham-City-Data/main/data/elections/results_precinct.csv")

# Every mayoral race, candidates only (no blanks or write-ins)
results |>
  filter(office == "Mayor", candidate_type == "candidate") |>
  group_by(election_date, type, candidate) |>
  summarize(votes = sum(votes), .groups = "drop")

The same files open in Excel, Python, Datawrapper or anything else that reads CSV.

What the columns mean

results_precinct.csv

Column Meaning
election_id Unique ID: date, level and type, e.g. 2023-11-07_municipal_general
election_date Date of the election
level municipal (City/Town) or state (state and federal offices, primaries)
type general, preliminary, special, town (pre-2018 annual town election), primary, presidential-primary
status official or unofficial (election-night) results
party For primaries, the party ballot; otherwise empty
race The race exactly as the clerk printed it
office Standardized office name, e.g. City Council At-Large, School Committee District, State Representative
office_district District number or name for district offices, e.g. 3 or 6th Middlesex
seats Number of seats being elected, when printed
candidate Candidate name as printed; Blanks and Write-ins are standardized
candidate_type candidate, blank, write-in, or response (Yes/No on ballot questions)
precinct Precinct as printed, including sub-precincts such as 9A
precinct_base Precinct without the sub-precinct letter (9A -> 9)
city_district City council district the precinct was in on that date (empty before 2012)
votes Votes

turnout_precinct.csv has the same election columns plus registered, ballots_cast and turnout_pct (always a percent from 0 to 100). For primaries there’s a row per party ballot as well as an all-voters row (empty party).

About precincts: Framingham’s precincts were redrawn after the 2020 Census. The 18-precinct map was used through the January 11 2022 special election; the 27-precinct map since the September 2022 state primary. Precinct “4” is a different place on each map, so always look at election_date (or use city_district, which is correct for each date).

Maps

The precinct files in data/gis/ work in any mapping tool. In R, make_precinct_map() in R/gis.R makes an interactive map of precincts colored by city council district and searchable by address:

source("R/load.R")
make_precinct_map("2023-11-07", show_house_districts = TRUE)

How the data are maintained

  • Sources. Local election results come from the Framingham City Clerk’s results PDFs. They’re turned into spreadsheets (with CometDocs or PDFTables for older elections, Adobe Acrobat from 2024 on), and every election is checked automatically: each row’s precinct numbers must add up to the clerk’s total, ballots can’t exceed registered voters, and so on. The checks for every election are in data/elections/validation_report.csv.
  • Automation. A scheduled GitHub Action looks for new results on the clerk’s page. When it finds some, it extracts and checks them and opens a pull request for a human to review before anything is published.
  • Reproducible. Everything in data/elections/ is rebuilt from data-raw/ by scripts/build_all.R; nothing there is edited by hand. The R code is in R/, and the README explains how to add an election.

This is an unofficial project and isn’t affiliated with the City of Framingham. Check official sources before relying on the data for anything important.
